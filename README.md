# あそぼう

子ども向けの、時間制限なし・減点なしの あそびアプリです。HTML 1ファイルで動きます。

**https://nekoko514.github.io/asobou/**

## あそび

メニューは種類ごとの「たな」に分けて並びます（🔍 くらべる・🎨 いろ・かたち・🔢 かず・💬 ことば・✏️ かく・🧩 パズル・🎵 おと・あそび）。たなとカードは種類ごとに同じ色です。iPad の横向きでは、ぜんぶ1画面に収まります（出すあそびが少ないときは、カードが大きくなります）。

| あそび | 内容 |
| --- | --- |
| おおきい ちいさい | 大きさのちがう同じ絵から選ぶ |
| かず | 1〜3こ のまとまりから選ぶ |
| なかま | くだもの・むし・やさい・おもちゃ の仲間を選ぶ |
| オノマトペ | ことば（ナデナデ など）に合う絵を選ぶ |
| いろ | 10色から選ぶ（あか と ピンク のような似た色は一緒に出さない） |
| かたち | まる・さんかく・しかく・ほし・ハート から選ぶ |
| おなじ | 見本と同じ絵を選ぶ |
| かげ | 見本のシルエットを選ぶ |
| きもち | うれしい・かなしい などの顔を選ぶ |
| ことば | ひらがなの言葉に合う絵を選ぶ |
| おおい すくない | 多いほう・少ないほうのまとまりを選ぶ |
| かたちはめ | 形の穴に、同じ形のピースをはめる（2→3→4こ） |
| えあわせ | どうぶつの顔を、横長のピースで組み立てる（2→3→4まい） |
| パターン | ●○●○… のくりかえしの、つづきを選ぶ |
| すうじ | 数字を見て、その数のまとまりを選ぶ（1〜6） |
| なかまはずれ | 3つのうち、仲間ではないものを選ぶ |
| きおく | 同じ絵を2枚さがす（2→3→4組） |
| しゃぼんだま | 割ってあそぶ自由あそび（記録なし） |
| ふうせん | 下から上がってくるふうせんを割る自由あそび（記録なし） |
| なぞり | 線を指でなぞる。15種類の形から、やさしい順に3つ（記録なし） |
| あいうえお | ひらがな46字を、五十音の順に1字ずつ、書く順になぞる。書いた字は「あいうえお ひょう」に はなまる（記録なし） |
| カタカナ | カタカナ46字を、あいうえお と同じように順になぞる（記録なし） |
| すうじ なぞり | 1〜10 を順になぞる（記録なし） |
| おえかき | 8色で自由に描く（記録なし） |
| もっきん | 色の板をたたくと音が鳴る。「うた」を選ぶと、次にたたく板が光る（かえるのうた・きらきらぼし・メリーさんのひつじ。記録なし） |
| いないいない ばあ | タッチすると布が上がって、どうぶつが「ばあ！」と出てくる。8回でおしまい（記録なし） |
| ぬりえ | 色を選んで、ぬりたい所をタッチ。線の中だけがぬれる。8まいの絵（記録なし） |
| てんつなぎ | 1から順に点をつなぐと絵が出る。点は 5〜6 → 7〜8 → 9〜10 と増える（記録なし） |
| めいろ | ゆびで どうぶつを動かしてゴールへ。3→4→5だん と広くなる（記録なし） |
| ことばづくり | 絵を見て、文字カードをことばの順にならべる（2→3→4文字） |
| こえの ものさし | マイクで声の大きさを見て、ちいさい（ありさん）・ふつう（ねこさん）・おおきい（ぞうさん）の3つで見せる。「じゆう」「いってみよう」「どんなとき」の3つのあそびかた（記録なし） |

課題は1回5問。まちがえても×は出ず、選んだものが薄くなるだけで、1回外すと正解の枠がそっと出ます。同じ答えは続けて出さず、正解の場所も3回続けて同じにはしません。

パズルは1回3つ。ピースは指で動かすほか、「ピースをタップ → 置く場所をタップ」でも置けます。ちがう場所に置くとピースが戻るだけで、1回まちがえると、そのピースと正しい場所に枠が出ます。

文字のなぞりは、お手本の字（M PLUS Rounded 1c）をそのまま表示し、書く順に1画ずつなぞると、なぞったところから字が緑に塗られていきます。いまなぞる画の上には点がならび、書きはじめは番号の丸（書く順）、おわりは星です。なぞると点が消えて緑がのびます。まだなぞっていない画には緑がはみ出さないようにしてあり（交わるところだけ緑になる）、最後までなぞると字全体が緑になります。なぞる道すじ（`LETTERS`）は画面には出さず、字の線の真ん中を通るように、フォントの字から作ってあります。あいうえお・カタカナ・すうじ なぞり は、はじめに「あいうえお ひょう」が出ます。書いた字には はなまるが つき、つぎに書く字が光ります（ひょうの字を押すと、その字から書けます）。書きはじめると五十音の順に1字ずつ つづき、上には いま書いている行（あ行 など）が出ます。いつでも右下の「おしまい」で終われて（3字以上でシール）、つぎは その字から。さいごの字（ん）まで書くと、はじめに もどります。

あそびを最後までやると、シールが1まいもらえます。ホームの「シール」で、ページのすきな所にはったり、うごかしたりできます（おえかき・ぬりえは、かいてから「できた」を押したとき）。

こえの ものさし は、声の大きさを「ものさし」と どうぶつで見せます。「じゆう」は声を出すと はりと絵がうごき、「いってみよう」は「ちいさい こえで『おはよう』」のように言われた大きさで言います（ねらった大きさの声が出ているあいだ、まわりの わっかが たまります）。「どんなとき」は「あかちゃんが ねてる」などの場面に合う声を えらんでから、その声で言います。合わなくても×はなく、しばらくすると「もうすこし ちいさく」などのヒントと「つぎへ」が出ます。2〜3さい向けのときは、ちいさい と おおきい だけになります。

お題（「あか さがして」など）は、端末の日本語の声で読みあげます。お題の白いラベルをタッチすると、もう一度読みます。てんつなぎでは数字を、ことばづくりでは文字とことばを読みます。

## 使い方

- iPad / iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます
- 音：えらべた・はまった・割れた・おしまい のときに、やわらかい短い音が鳴ります。まちがえたときは鳴りません。保護者メニューで切り替えられます（鳴らないときは、端末の音量と消音スイッチを確認してください）
- 保護者メニュー：画面の右上を3秒長押し（記録の確認、音・よみあげの切り替え、こえの ものさし の ちょうせい、シールと あいうえお ひょう のリセット、年齢に合わせた切り替え、メニューに出すあそびの選択、スケジュールの編集）
- こえの ものさし：はじめて開くと、マイクの許可をたずねられるので「許可」を押してください。声の大きさの きじゅんは、はじめは まわりの静かさから決めます。ずれるときは、保護者メニューの「こえの ものさし」で、おとなが ふつうの声で3びょう話して はかりなおせます（さかいの細かい調整もできます）
- よみあげ：iPad の声を使います。声の種類は「設定 → アクセシビリティ → 読み上げコンテンツ → 声」で変えられます
- 年齢の切り替え：「2〜3さい」にすると、えらぶものが2つになり、パズル・きおくのピースも少なくなります。読めなくても遊べるあそびだけメニューに出ます。「4さい〜」で全部に戻ります
- iPad の「アクセスガイド」（設定 → アクセシビリティ）を使うと、アプリから出られなくできます

## 記録について

記録・スケジュール・シール・あいうえお ひょう は、その端末のブラウザの中（localStorage）だけに保存され、どこにも送信されません（文字の形は Google Fonts から読みこみますが、記録は送られません）。
マイクの音は、こえの ものさし で声の大きさを見るためだけに使い、録音も送信もしません。マイクを使うのは、こえの ものさし の画面と、保護者メニューで ちょうせいしているあいだだけです。
端末やブラウザが変わると引き継がれません。iPhone / iPad では、ホーム画面から開いた場合と Safari で開いた場合でも別々になるので、どちらか一方で使ってください。
