# あそぼう

子ども向けの、時間制限なし・減点なしの あそびアプリです。HTML 1ファイルで動きます。

**https://nekoko514.github.io/asobou/**

## あそび

| あそび | 内容 |
| --- | --- |
| おおきい ちいさい | 大きさのちがう同じ絵から選ぶ |
| かず | 1〜3こ のまとまりから選ぶ |
| なかま | くだもの・むし・やさい・おもちゃ の仲間を選ぶ |
| オノマトペ | ことば（ナデナデ など）に合う絵を選ぶ |
| いろ | 10色から選ぶ（あか と ピンク のような似た色は一緒に出さない） |
| かたち | まる・さんかく・しかく・ほし・ハート から選ぶ |
| おなじ | 見本と同じ絵を選ぶ |
| かげ | 見本のシルエットを選ぶ |
| きもち | うれしい・かなしい などの顔を選ぶ |
| ことば | ひらがなの言葉に合う絵を選ぶ |
| おおい すくない | 多いほう・少ないほうのまとまりを選ぶ |
| かたちはめ | 形の穴に、同じ形のピースをはめる（2→3→4こ） |
| えあわせ | どうぶつの顔を、横長のピースで組み立てる（2→3→4まい） |
| パターン | ●○●○… のくりかえしの、つづきを選ぶ |
| すうじ | 数字を見て、その数のまとまりを選ぶ（1〜6） |
| なかまはずれ | 3つのうち、仲間ではないものを選ぶ |
| きおく | 同じ絵を2枚さがす（2→3→4組） |
| しゃぼんだま | 割ってあそぶ自由あそび（記録なし） |
| ふうせん | 下から上がってくるふうせんを割る自由あそび（記録なし） |
| なぞり | 線を指でなぞる。15種類の形から、やさしい順に3つ（記録なし） |
| あいうえお | ひらがな46字を、書く順に1画ずつなぞる（記録なし） |
| カタカナ | カタカナ46字を、書く順に1画ずつなぞる（記録なし） |
| すうじ なぞり | 1〜10 を書く順になぞる（記録なし） |
| おえかき | 8色で自由に描く（記録なし） |

課題は1回5問。まちがえても×は出ず、選んだものが薄くなるだけで、1回外すと正解の枠がそっと出ます。同じ答えは続けて出さず、正解の場所も3回続けて同じにはしません。

パズルは1回3つ。ピースは指で動かすほか、「ピースをタップ → 置く場所をタップ」でも置けます。ちがう場所に置くとピースが戻るだけで、1回まちがえると、そのピースと正しい場所に枠が出ます。

文字のなぞりは、お手本の字（M PLUS Rounded 1c）をそのまま表示し、書く順に1画ずつなぞると、なぞったところから字が緑に塗られていきます。いまなぞる画は少し濃く表示し、最後までなぞると字全体が緑になります。なぞる道すじ（`LETTERS`）は画面には出さず、字の線の真ん中を通るように、フォントの字から作ってあります。字は五十音の並びでとなり合う3文字が出ます（あ・い・う → か・き・く…）。

## 使い方

- iPad / iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます
- 音：えらべた・はまった・割れた・おしまい のときに、やわらかい短い音が鳴ります。まちがえたときは鳴りません。保護者メニューで切り替えられます（鳴らないときは、端末の音量と消音スイッチを確認してください）
- 保護者メニュー：画面の右上を3秒長押し（記録の確認、音の切り替え、年齢に合わせた切り替え、メニューに出すあそびの選択、スケジュールの編集）
- 年齢の切り替え：「2〜3さい」にすると、えらぶものが2つになり、パズル・きおくのピースも少なくなります。読めなくても遊べるあそびだけメニューに出ます。「4さい〜」で全部に戻ります
- iPad の「アクセスガイド」（設定 → アクセシビリティ）を使うと、アプリから出られなくできます

## 記録について

記録やスケジュールは、その端末のブラウザの中（localStorage）だけに保存され、どこにも送信されません（文字の形は Google Fonts から読みこみますが、記録は送られません）。
端末やブラウザが変わると引き継がれません。iPhone / iPad では、ホーム画面から開いた場合と Safari で開いた場合でも別々になるので、どちらか一方で使ってください。
