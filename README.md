# あそぼう

子ども向けの、音なし・時間制限なし・減点なしの あそびアプリです。HTML 1ファイルで動きます。

**https://nekoko514.github.io/asobou/**

## あそび

| あそび | 内容 |
| --- | --- |
| おおきい ちいさい | 大きさのちがう同じ絵から選ぶ |
| かず | 1〜3こ のまとまりから選ぶ |
| なかま | くだもの・むし・やさい・おもちゃ の仲間を選ぶ |
| オノマトペ | ことば（ナデナデ など）に合う絵を選ぶ |
| いろ | 10色から選ぶ（あか と ピンク のような似た色は一緒に出さない） |
| かたち | まる・さんかく・しかく・ほし・ハート から選ぶ |
| おなじ | 見本と同じ絵を選ぶ |
| かげ | 見本のシルエットを選ぶ |
| きもち | うれしい・かなしい などの顔を選ぶ |
| ことば | ひらがなの言葉に合う絵を選ぶ |
| おおい すくない | 多いほう・少ないほうのまとまりを選ぶ |
| かたちはめ | 形の穴に、同じ形のピースをはめる（2→3→4こ） |
| えあわせ | どうぶつの顔を、横長のピースで組み立てる（2→3→4まい） |
| しゃぼんだま | 割ってあそぶ自由あそび（記録なし） |
| ふうせん | 下から上がってくるふうせんを割る自由あそび（記録なし） |

課題は1回5問。まちがえても×は出ず、選んだものが薄くなるだけで、1回外すと正解の枠がそっと出ます。同じ答えは続けて出さず、正解の場所も3回続けて同じにはしません。

パズルは1回3つ。ピースは指で動かすほか、「ピースをタップ → 置く場所をタップ」でも置けます。ちがう場所に置くとピースが戻るだけで、1回まちがえると、そのピースと正しい場所に枠が出ます。

## 使い方

- iPad / iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます
- 保護者メニュー：画面の右上を3秒長押し（記録の確認、メニューに出すあそびの選択、スケジュールの編集）
- iPad の「アクセスガイド」（設定 → アクセシビリティ）を使うと、アプリから出られなくできます

## 記録について

記録やスケジュールは、その端末のブラウザの中（localStorage）だけに保存され、どこにも送信されません（文字の形は Google Fonts から読みこみますが、記録は送られません）。
端末やブラウザが変わると引き継がれません。iPhone / iPad では、ホーム画面から開いた場合と Safari で開いた場合でも別々になるので、どちらか一方で使ってください。
